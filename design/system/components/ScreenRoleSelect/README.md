# ScreenRoleSelect
Sets `professionalType` (DOCTOR · RESIDENT · STUDENT) and nothing else. Three selectable rows (not cards) with the audience line and what the profile costs: DokTool Pro for doctors and residents, free for students. Pharmacist and other health professionals are future roadmap and are not offered. Demo is not a profile — it starts from Welcome.

States: none selected (Continue disabled) · selected · changing type later from Profil (warns that a new status verification is needed; favorites, activity and settings are kept).
