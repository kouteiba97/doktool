# ScreenVerifyIdentity
Identity step (separate from professional and specialty steps). Camera-first on mobile, with automatic legibility and name reading; the user sees what was read, never a thumbnail of the document after capture.

States: not started · capturing (full-screen camera with guides) · reviewing capture · uploading · legible (name read) · illegible (blur/glare/cut, how to fix) · name mismatch with account (asks to correct the account name or explain) · offline (captures kept locally, sent on reconnect) · "Plus tard" (app usable in read mode; banner on Home).
