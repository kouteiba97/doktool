# ScreenPregnancyDesktop

> **Future roadmap — not V1.** Belongs to a deferred module (Drug Database, document generation, or partnerships). Not built, routed, searchable or shown as "coming soon" in V1 (Locks L31, L32). See section 25.
Pregnancy view for one drug. Trimester tabs carry the conduct badge only where it is a clinical instruction (Contre-indiqué, Éviter, Prise ponctuelle — icon + word). Each trimester shows risk context, the neutral evidence meter with its level word and population, clinical considerations, documented alternatives and the evidence footer. The side list compares trimesters. Conduct ("what to do") and evidence level ("how sure") are always shown separately; there is no safe/unsafe verdict anywhere.

States: absence de données (full no-evidence block: "Absence de données — ce n'est pas une preuve d'innocuité", alternatives) · conflicting sources (info Alert naming both sources and the reviewer's synthesis) · under review · cached.
