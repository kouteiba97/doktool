# ScreenTabletDrug

> **Future roadmap — DokTool Web (not V1).** V1 has no user web application (Lock L33). This card is a *layout* reference for a future web client; its content predates V1 and may show deferred modules. See section 25.
Tablet portrait (640–1023px): the sidebar collapses to the 64px rail, the section nav becomes tabs, tables keep full columns, content uses the full width minus 24px gutters. Landscape tablets (≥ 1024) get the desktop layout. The prescription editor on tablet landscape shows the paper preview beside the editor; in portrait the preview is a toggle.
