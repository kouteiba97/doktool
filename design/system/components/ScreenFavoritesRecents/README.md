# ScreenFavoritesRecents
Profile › Activité et favoris. Two segments: **Favoris** (reference models and calculators, grouped by type, favorites-first everywhere else in the app) and **Activité** — the user's research history: searches, models consulted, calculations, grouped by day, filterable. The history is private to the user (admins see counts only), capped, and clearable; calculator input values never leave the device (Lock L42).

States: empty (first use) · a favorite whose model is no longer available (neutral row with *Retirer*) · history cleared (confirmation sheet, then empty) · offline (cached; changes sync later).
