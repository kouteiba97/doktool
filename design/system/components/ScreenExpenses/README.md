# ScreenExpenses
Operating expenses entered by finance (date, item, category, amount, receipt, author). They feed *Charges d’exploitation* and therefore *Résultat net* in the Rentabilité block — never the revenue strip. Missing receipts are flagged with icon + word. Replaces the v2.1 `ScreenExpensesRefunds`: there is no refund list or refund decision in V1.
