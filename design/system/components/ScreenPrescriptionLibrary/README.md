# ScreenPrescriptionLibrary

> **Future roadmap — not V1.** Belongs to a deferred module (Drug Database, document generation, or partnerships). Not built, routed, searchable or shown as "coming soon" in V1 (Locks L31, L32). See section 25.
Library of system and personal templates: search by diagnosis, drug or name; chips (Tous, Mes modèles, Favoris, Récents); specialty filter; rows with diagnosis tag, drugs, source and version, last use, primary "Utiliser" and a row menu (Dupliquer, Renommer, Favori, Supprimer for own templates). When a system template is revised, an info line explains what changed and that personal copies are untouched.

States: first use (EmptyState + 3 suggested templates for the user's specialty) · no match (clear filters) · offline (templates from pack; "Mes modèles" always local) · restricted (student: "S'entraîner", watermark note).
