# ScreenPermissions
The V1 grant matrix (section 03): presets SUPER_ADMIN, VERIFICATION_REVIEWER, LIBRARY_MANAGER, CALCULATOR_EDITOR, CLINICAL_REVIEWER, FINANCE_ADMIN, ANALYST × grants. Temporary grants show their duration (`verification.documents.view`, 2 h). Separation-of-duties rules are enforced by the API and restated here. No drug, template, partnership or refund grant exists in V1.
