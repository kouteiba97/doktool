# ScreenPrescriptionValidation

> **Future roadmap — not V1.** Belongs to a deferred module (Drug Database, document generation, or partnerships). Not built, routed, searchable or shown as "coming soon" in V1 (Locks L31, L32). See section 25.
The clinical validation step that runs before any export (inline in the editor when clear; this full view when something is found). Findings are grouped by severity and each offers a one-click fix; passed checks are listed so the absence of warnings is explicit. Contraindications block export unless the doctor overrides with a reason (kept in the document history, never printed, never sent to analytics). DokTool never silently changes a dose.
