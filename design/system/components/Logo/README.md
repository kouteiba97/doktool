# Logo
The DokTool mark is now a vector master set (`assets/Logos/*.svg`), redrawn faithfully from the supplied logo: rounded tablet frame (blue → teal gradient), stethoscope, frosted bar with the ECG trace and end dot, and the DOKTOOL logotype (Montserrat ExtraBold, outlined; navy DOK, blue → teal TOOL). The logo files are the only place gradients exist in the product.

## Files and use
| File | Use |
|---|---|
| `doktool-logo-horizontal.svg` / `-dark.svg` | Sidebar (240px, 22px tall), login, e-mail headers, top of documents' footer credit |
| `doktool-logo-vertical.svg` / `-dark.svg` | Welcome, splash, pricing, marketing |
| `doktool-symbol.svg` / `-dark.svg` | 24px and above: mobile Home header (36px), console bar (22px), collapsed rail (28px) |
| `doktool-mark-small.svg` / `-dark.svg` | 16–32px: favicon, tab icon, notification icon — optical variant (frame + one heavy trace; stethoscope and bar omitted because they turn to noise below 32px) |
| `doktool-symbol-mono-ink.svg` / `-mono-white.svg`, `doktool-logo-horizontal-mono-*.svg` | Single-ink: printed documents, watermarks, fax/scan-safe headers, navy console, empty-state mark (at 35% opacity) |
| `doktool-wordmark.svg` / `-dark.svg` | Logotype alone (rare: partner co-branding) |
| `doktool-app-icon.svg` (+ PNG 1024/512/180) | App stores and home screens: mark on `brand` #0a5c78, 22% corner radius |
| `doktool-favicon.svg` (+ PNG 16/32/48/64) | Web favicon |
| `doktool-trace.svg`, `doktool-trace-marker.svg` | The ECG trace (48×12) and section marker (16×10), `currentColor` |
| `*.png` from v1 | Source raster, archived; do not use in product |

## Rules
Minimum size 16px (small mark) / 24px (full symbol) / 12px wordmark cap height. Clear space ½ symbol height. Dark grounds use the `-dark` files (white DOK, lightened TOOL, cooler panel so it does not glow). Never recolour to a semantic colour, never place on a gradient or a photo, never set UI text in the logotype, never animate the mark (the trace animates, the logo does not).
