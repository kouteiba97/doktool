# ScreenSettings
Mobile settings. **Apparence**: Clair · Sombre · Appareil (follows the OS). **Langue / Language**: `LanguageSwitch` (FR/EN), applied instantly without restart; the helper states that reference PDFs keep their own language. Then Notifications, Sécurité (password, connected devices, sign out elsewhere), Données et hors ligne (ScreenOfflinePacks), Compte (edit profile, delete account with a typed confirmation), À propos (app and data versions), **Se déconnecter**.

States: saved (inline check) · failure (value reverts with a toast) · log out confirmation (sheet) · delete account (typed confirmation; subscription is not refunded — stated in the sheet).
