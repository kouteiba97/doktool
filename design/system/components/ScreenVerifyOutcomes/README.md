# ScreenVerifyOutcomes
The three outcomes of a verification, on mobile. The timeline shows **identity** and **professional status** as separate cases (section 06, 26): identity can be verified while status is in review or needs a new document. "Vérifié" leads to the plans — checkout opens only once status is verified (no-refund policy). A step to redo is stated in plain language with one action; red is reserved for a definitive rejection with its reason (not shown), never for a fixable document.

States also covered by the pattern: appeal (after a second rejection, different reviewer) · expiring (60/14-day reminders; renewal reuses unchanged identity) · history list.
