# ScreenCertificateEditor

> **Future roadmap — not V1.** Belongs to a deferred module (Drug Database, document generation, or partnerships). Not built, routed, searchable or shown as "coming soon" in V1 (Locks L31, L32). See section 25.
Certificates are structured forms, not a text editor: type segmented control, patient fields (not retained after export by default), dates with automatic duration and return date, exits and nature as controls, an optional free mention with the medical-secrecy rule stated. The legal wording, numbers in words and signature block come from the versioned template.

States: invalid dates (end before start: critical) · long duration (> 15 days: warning "prolongation au-delà de 15 jours : vérifier les règles CNAS") · student (not available: EmptyState restricted) · pending verification (preview only, watermark "APERÇU — NON VALIDE") · offline (works, export local).
