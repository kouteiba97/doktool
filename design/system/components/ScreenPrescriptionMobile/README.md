# ScreenPrescriptionMobile

> **Future roadmap — not V1.** Belongs to a deferred module (Drug Database, document generation, or partnerships). Not built, routed, searchable or shown as "coming soon" in V1 (Locks L31, L32). See section 25.
Mobile prescription flow: editor list with compact rows, the validation line, a floating glass add field, and one primary Export. Tapping a row opens its editor in a bottom sheet (48px inputs, presets). Export opens the ExportSheet. Offline, PDF/print/copy/image work locally; share-by-link queues with a visible "En attente" state.
