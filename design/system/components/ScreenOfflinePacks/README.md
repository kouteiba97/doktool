# ScreenOfflinePacks
Offline for every real account — doctors, residents **and students** — covering only V1 content the account is entitled to (section 18): reference PDFs, published calculator versions (installed after their tests pass on the device), favorites, activity and settings. No drug, pediatric, pregnancy or interaction packs; no export queue. Shows last sync and data version, storage used, per-type state (À jour · nouveaux · mise à jour disponible), download scope (all models or favorites only), mobile-data switch, and removal.

States: downloading (progress inside the row) · update available · outdated (> 30 days, warning line) · sync failed (cause + retry) · low storage (< 200 Mo) · lost entitlement (protected copies removed at next online launch, stated once).
