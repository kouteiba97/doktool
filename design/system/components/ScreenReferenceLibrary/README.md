# ScreenReferenceLibrary
The Bibliothèque tab: segmented **Ordonnances · Certificats · Calculateurs**, a search field scoped to the current type, and an A–Z list with favorites first (about 10 rows visible). A row is the model's display title (UI language, falling back to French) and one action, **Voir le modèle / View model**. There is no "new", "blank model", editor or floating button — DokTool does not author models; the Super Admin uploads them (section 13, Lock L31). No category chips in V1 (open question Q8).

Certificates use the identical screen (type = CERTIFICATE). Locked rows (Demo, Student, unpaid) keep their place with a lock and a reason word instead of the action. States: ScreenReferenceLibraryStates.
