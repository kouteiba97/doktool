# ScreenSearchMobile
Full-screen search overlay (raised centre tab or the Home field). Chips with counts filter in place; groups show 3 rows each: Ordonnances, Certificats, Calculateurs — the only V1 result types; no drug result exists (Lock L32). Tap opens the destination (reference viewer or calculator); long-press or `⋯` opens a sheet with *Voir le modèle / Ouvrir* and *Ajouter aux favoris*. Matches are emphasised by weight, not colour. Queries match French and English titles and admin synonyms, accent-insensitive and typo tolerant (section 12).

For Demo, Student and unpaid contexts, rows the context cannot open keep their place with a lock and a reason word (ScreenSearchStates, ScreenLockedStates).
