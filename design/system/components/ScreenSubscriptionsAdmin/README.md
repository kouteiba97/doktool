# ScreenSubscriptionsAdmin
Plan catalogue (code, name, audience, price, duration, version, purchasable, active subscribers) and, in the second tab, the subscription list (user · plan · status · start · end · payment method · last transaction). The includes / not-included lists edited here are exactly what the mobile plan screen shows before payment. Editing a plan creates a new version; running subscriptions keep theirs. Students are not in the catalogue — free access is an entitlement tier, not a plan. Grants: `subscriptions.read`, `subscriptions.plans.write`. Prices illustrative (open question Q3).
