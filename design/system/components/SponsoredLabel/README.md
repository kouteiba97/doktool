# SponsoredLabel

> **Future roadmap — not V1.** Belongs to a deferred module (Drug Database, document generation, or partnerships). Not built, routed, searchable or shown as "coming soon" in V1 (Locks L31, L32). See section 25.
The visual boundary between clinical content and commercial content. Sponsored material always carries this label and this ground; clinical content never does.

**Anatomy** the uppercase `sponsored` badge, a block on `sponsored-soft` with a hairline border, title, a disclosure line naming the sponsor and stating that it does not influence clinical results, a "Pourquoi ce contenu ?" link and a dismiss button. **Placement** only below all clinical groups in search results, in a labeled module banner slot, or as an educational article card; never inside a drug page, a dose result, a prescription, or an evidence block.

**Consumer provides** `{sponsor, title, href, placement}`. The `sponsored` hue is reserved for this component across the whole product.
