# Logos
Vector master set (v2), redrawn faithfully from the supplied DokTool logo. SVG files are the masters; PNGs are exports for stores and favicons. The logo files are the only gradients in the product.

| File | Use |
|---|---|
| doktool-logo-horizontal.svg / -dark.svg | Sidebar (22px tall), login, e-mail headers |
| doktool-logo-vertical.svg / -dark.svg | Welcome, splash, pricing |
| doktool-symbol.svg / -dark.svg | Mark alone from 24px: mobile Home header, console bar, collapsed rail |
| doktool-mark-small.svg / -dark.svg | 16–32px optical variant: favicon, tab icon, notification icon |
| doktool-symbol-mono-ink.svg / -mono-white.svg | Single-ink mark: printed documents, watermarks, empty-state mark (35 % opacity) |
| doktool-logo-horizontal-mono-ink.svg / -mono-white.svg | Single-ink lockup: navy console, print |
| doktool-wordmark.svg / -dark.svg | Logotype alone (co-branding only) |
| doktool-app-icon.svg + doktool-app-icon-1024/512/180.png | Stores and home screens (mark on `brand` #0a5c78, 22 % radius) |
| doktool-favicon.svg + doktool-favicon-16/32/48/64.png | Web favicon |
| doktool-trace.svg, doktool-trace-marker.svg | The ECG trace (loader) and section marker; `currentColor` |
| doktool-logo-horizontal-1024.png / -dark-1024.png | Raster lockups for documents and e-mail clients that block SVG |

Single-ink files are drawn in their own ink (`<img>` cannot inherit colour): pick the ink or white file for the ground. Minimum sizes: small mark 16px, full symbol 24px, wordmark cap height 12px. Clear space: ½ symbol height.
